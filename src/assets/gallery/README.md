# Photo Gallery Assets Directory

Place your high-resolution photos in this folder:
- `performance-solo.jpg`
- `annual-show-ensemble.jpg`
- `studio-tatkar.jpg`
- `abhinaya-stage.jpg`
- `ghungroo-pooja.jpg`
- `adult-batch.jpg`
- `tarana-finale.jpg`
- `junior-mudras.jpg`

Once placed, reference them in `src/data/content.js` under `galleryPhotos`.
The Gallery component will automatically load and render them in the masonry grid and fullscreen lightbox.
